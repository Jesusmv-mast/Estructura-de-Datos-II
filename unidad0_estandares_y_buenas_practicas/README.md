# Unidad 0: Estándares y buenas prácticas de codificación

En esta unidad se trabaja la importancia de escribir código legible, mantenible y consistente. El estándar principal para Python es **PEP 8**, complementado por **PEP 257** para docstrings.

## Contenido

- [Guía de PEP 8 aplicada a una estructura de datos](tareas/pep8/README.md)

## Objetivos

- Conocer las reglas principales de PEP 8.
- Aplicar nombres descriptivos y consistentes.
- Documentar clases y funciones con docstrings.
- Escribir ejemplos correctos de una estructura de datos simple (una pila).
- Identificar malas prácticas y saber corregirlas.
