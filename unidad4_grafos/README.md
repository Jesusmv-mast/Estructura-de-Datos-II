# Unidad 4: Grafos

En esta unidad se estudian los **grafos** como estructura de datos: vértices, aristas, representaciones y recorridos.

## Contenido

- [Representación de grafos, DFS y BFS](algoritmos/README.md)

## Temas

- Conceptos básicos: vértices, aristas, caminos, ciclos y conectividad.
- Grafos dirigidos y no dirigidos.
- Representación con matriz de adyacencia.
- Representación con lista de adyacencia.
- Recorrido en anchura (BFS).
- Recorrido en profundidad (DFS).
- Detección de ciclos y ordenamiento topológico.

## Algoritmos incluidos

| Archivo | Descripción |
| --- | --- |
| [`grafo.py`](algoritmos/grafo.py) | Grafo no dirigido con lista y matriz de adyacencia |
| [`dfs.py`](algoritmos/dfs.py) | DFS recursivo e iterativo |
| [`bfs.py`](algoritmos/bfs.py) | BFS y distancias en grafos no pesados |
